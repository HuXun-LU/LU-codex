## 项目简介 Introduction
《逻辑宇宙·信息‑拓扑本体论》是一套**自然哲学/元物理（前物理）研究纲领**。
不推翻标准物理的数学方程，而是替换底层本体叙事：
唯一实在是光场晶格节点阵列；唯一基础操作为自检闭环「态 ➜ 非态 ➜ 态」；
世间全部现象（物理、化学、生命），均是反旋链不同开闭拓扑构型的投影读数。

> 万物差异，仅源于同一条反旋自检链的不同拓扑连接与演化命运。
> 闭合则为光，环流则为磁，弥散则为电，远解则为引，插入则为能级，解体则为膨胀，封存则为体积能量。
> 世界不是由物质堆砌而成，而是由唯一的存在性操作自演化而成。

## 重要定位声明 Statement‑Read‑First
1. 本作品是公理‑推演型思想框架，**不是完成定量标定、未经同行评审的物理教科书**。
2. 不否定、不推翻现有实验数据与标准方程；标准科学方程在适用范围继续有效，本框架仅替换底层本体解释。
3. 全书全部关系式为**拓扑比例映射，不含标定常数、绝对数值**；所有“预言”属于原则性可检验方向，不是强物理判决。
4. 书中涉及衰老、癌变、营养推演仅为假说，**不可作为医疗、膳食、用药依据**。
5. 本纲领开放迭代，允许未来证伪、剪枝、重组与变异。
6. ⚠️禁止脱离完整公理链单独截取局部命题阅读，断章取义会造成误解。

> This manuscript is a natural‑philosophy meta‑physical research programme, NOT quantitatively‑calibrated physical theory and has not undergone peer review.
